# 📸 EXIF Rename Helper

Простой bash-скрипт, который помогает аккуратно рассортировать фотографии,  
переименовывая их по **дате и времени съёмки**, извлечённым из **EXIF-метаданных**.

---

## 🧠 Зачем это нужно

Когда фотографии копируются с разных камер или карт памяти,  
у них часто совпадают имена — вроде `DSC0001.NEF`, `DSC0001.JPG` и т.д.  
Этот скрипт решает проблему дубликатов и помогает навести порядок в архивах:

- Извлекает из EXIF поле `DateTimeOriginal`
- Переименовывает файлы в формат  
YYYY.MM.DD.HH.MM.SS_originalName.ext

yaml
Copy code
- Работает с любыми масками (например, `*.jpg`, `*.png`, `D*NEF`)
- Может запускаться в «сухом» режиме без изменений (`--dry-run`)

---

## ⚙️ Пример использования

```bash
# Переименовать все D*NEF файлы в текущей папке
./Exifer

# Указать свою папку и маску
./Exifer --folder /mnt/photos --mask '*.jpg'

# Проверить, что будет сделано, без реальных изменений
./Exifer -m '*.png' -n
🧩 Аргументы
Параметр	Короткая форма	Описание
--folder <путь>	-f	Каталог, в котором искать файлы (по умолчанию текущий)
--mask <шаблон>	-m	Маска файлов, например *.jpg, *.png, D*NEF
--dry-run	-n	Только показать, что будет сделано, без изменений
--help	-h	Вывести справку

```

⚠️ Замечания
Скрипт не заходит в подкаталоги — работает только с указанной папкой. Так и задумано. 

Если в EXIF нет даты съёмки (DateTimeOriginal), файл не переименовывается.

Если у файла уже есть похожее имя, возможен конфликт — скрипт перезаписывает без подтверждения.

Создан из любви к порядку в архивах и минимализму.
Полезен тем, кто хранит фотографии с камер, дронов или телефонов
и хочет разложить всё по датам.
